# AI, explained

A small, responsive AI explainer website with a light pink palette and a whimsical tone.

## Files

- `index.html` — page content and accessible semantic structure
- `styles.css` — responsive styles and illustration
- `script.js` — the interactive prompt example

## Preview locally

Open `index.html` in a browser, or run a local server from this folder:

```sh
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create a public GitHub repository named `ai-project`.
2. Upload `index.html`, `styles.css`, `script.js`, and `.nojekyll` to the repository root.
3. Open **Settings → Pages** and select **Deploy from a branch**, `main`, and `/(root)`.
4. After the deployment finishes, the website URL will be `https://YOUR-USERNAME.github.io/ai-project/`.

The page text stays below 1,000 words. It links factual claims to the OECD, NIST, Reuters and the South China Morning Post, and includes a short, honest note about how AI was used in the project.
